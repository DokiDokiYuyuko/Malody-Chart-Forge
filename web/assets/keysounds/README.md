# Key sounds

Source: [Kenney — Interface Sounds](https://kenney.nl/assets/interface-sounds), version 1.0 (2020).

License: CC0 1.0 Universal. The original `LICENSE.txt` is included alongside the six unmodified OGG samples.

| UI option | Original sample |
| --- | --- |
| 清脆点击 | click_001.ogg |
| 轻柔点按 | click_005.ogg |
| 机械开关 | switch_001.ogg |
| 短促滴答 | tick_001.ogg |
| 清亮拨弦 | pluck_001.ogg |
| 玻璃轻响 | glass_001.ogg |

The browser decodes samples once and plays them through Web Audio. Playback is limited to 150 ms with a short fade at the tail so sustained/dense key input does not accumulate long effects. Sample files themselves are unmodified. Samples are application resources and are not included in generated MCZ packages.
