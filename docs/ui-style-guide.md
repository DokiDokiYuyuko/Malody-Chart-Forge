# 星轨谱面工坊 · Startrail 界面风格

延续音游轨道的切角、色条与斜体字。操作区域有辨识度，信息区域保持清晰，装饰服务于操作层级。

## 基础色与文字

主题提供五套有明确色彩方向的界面：晴空轨道（冰蓝 `#d6eaf7`、薄荷 `#e0f4ef`）、蜜桃唱片（杏桃 `#f7ded4`、奶油 `#f7eee0`）、月雾花园（鸢尾雾 `#e6eafa`、柔紫 `#f1eaf8`）、海盐星潮（海盐蓝 `#d8eef1`、湖水青 `#e5f3f1`）、薄荷夜航（曜石黑 `#040b08`、荧光薄荷 `#85f1bc`）。

四套浅色主题共用墨色文字和统一组件层级；暗色主题使用独立表面与边框。Easy 到 Lunatic 的六档色在所有主题中维持相同含义。

中文标题使用系统无衬线字体与适度加粗；英语难度和主要操作使用 Bahnschrift / Arial Black 的粗斜体。辅助信息使用正常字形，避免整页斜体、发光或高饱和色。

## 控件层级

- 主要操作：深蓝底、浅色文字、青色底边；生成按钮保留四轨符号。
- 次要操作：浅底、细描边、局部切角；导航的当前项使用深蓝底。
- 辅助操作：文字和小图标；删除使用红色文字，避免误认作下载。
- 六档难度：使用统一的绿、蓝、金、紫、粉、红色映射；工作台、统计和曲包标签一致。
- 输入项：安静的浅色表面，聚焦时出现青色边线；数值和单位清晰分开。

## 页面组织

工作台保留紧凑的音乐、流速、难度和时间轴区域；桌面预览与统计面板上下对齐。
选歌侧栏使用上传符号和步骤导航，引导搜索、上传、设置难度。
曲包页面以封面为主要视觉，显示引擎、状态、难度标签和操作，保留分页与筛选。

## 外观主题与动态效果

网页名称使用「星轨谱面工坊」，副标题为「Startrail · Malody 4K」；仓库名称仍为 Malody-Chart-Forge。
顶部「设置」紧随工作台和曲包导航，三个入口保持一致高度和对齐。设置使用原生对话框，支持键盘焦点、Escape 关闭和返回触发按钮。

- 晴空轨道：以冰蓝、薄荷和淡粉的柔和渐变构成背景，少量星点与斜向轨迹增加层次；内容卡片保持明亮、清楚。
- 蜜桃唱片、月雾花园、海盐星潮：分别以暖杏与玫瑰、鸢尾与月光蓝、海盐与湖水青构成浅色配色；同一组件使用主题变量，避免只给背景换色。
- 薄荷夜航：以亮黑、墨绿和荧光薄荷绿构成背景与面板，粉色作为少量辅助强调；暗色覆盖表单、曲包、统计、弹窗和预览画布。
- 曲包卡片与歌曲头图采用 YouTube 横图比例 `16:9`，图片完整显示；手机端曲包继续使用横向完整封面。
- 难度保留绿、蓝、金、紫、粉、红六色，不随主题改变含义。高亮和发光集中于操作反馈、边缘与主要按钮，不用于大段文字。
- 鼠标流星拖尾可以单独关闭。流星短暂淡出，停止移动后不继续绘制；移动设备、时间轴拖动和谱面区域不产生拖尾。系统要求减少动态效果时停用拖尾。
- 外观选择只保存在当前浏览器；刷新后保留。恢复外观默认只重置主题与拖尾，不改变生成参数或曲包。

## 约束与维护

控件风格集中于 `web/arcade.css`；主题覆盖集中于其后的 `web/themes.css`。外观保存、对话框和拖尾由 `web/appearance.js` 管理。优先使用共享变量和控件组，避免给每个按钮单独添加不同装饰。
只在悬停、选中、聚焦等操作反馈中使用短过渡；支持减少动态效果。保留键盘焦点和明确的禁用状态。
改动后验证宽屏、1280×720 短窗口、平板和手机尺寸，以及 16:9 封面显示、搜索筛选、分页、预览与设置切换。

外观偏好与流星生命周期的单元检查：`node --test tests/test_appearance.cjs`。视觉检查还应覆盖五款主题、刷新后的偏好恢复、拖尾开关、设置弹窗的手机布局与 16:9 封面。
